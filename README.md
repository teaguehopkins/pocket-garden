# Mobile game prototypes

Single-file HTML prototypes for a mobile, offline-friendly puzzle game.

- `prototypes/garden.html` — Pocket Garden (current focus): draft species, stack rule cards, plant through three seasons.
- `prototypes/racer.html` — Drift Circuit: ship-part draft + card-based race.
- `prototypes/heist.html` — Night Crew: crew draft + room-clearing heist.

Open any file in a browser to play.
